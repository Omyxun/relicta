3-Step Telegram Setup Guide (@BotFather & Chat ID)
  1. Message @BotFather on Telegram, send /newbot, and copy the HTTP API Bot Token (or leave blank if the server admin configured a shared token).
  2. Open a chat with your newly created bot and click Start (bots cannot initiate messages until you message them first).
  3. Message @userinfobot or visit https://api.telegram.org/bot<TOKEN>/getUpdates to find your numeric chat_id.
